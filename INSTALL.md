# Installing Rubati on Android

**Preparation only: the APK release is not publicly available yet.** Use these
instructions after the owner has published the approved beta.

1. Open the [official Rubati releases](https://github.com/btalexon001/rubati-downloads/releases)
   and choose `v1.0.0-beta.1`.
2. Download `rubati-v1.0.0-beta.1.apk` from that release's Assets. The source-code
   ZIP/TAR files generated by GitHub are not the Android installer.
3. If you can calculate a checksum, compare the APK's SHA-256 with
   [SHA256SUMS.txt](SHA256SUMS.txt). Do not install a file whose checksum differs.
4. Open the APK on an Android 7.0 or newer phone. If Android asks, allow
   installation from the browser or file manager used for this download.
   Limit that permission to this installer and turn it off afterward. Do not
   disable Play Protect or bypass a security warning.
5. Follow Android's installation prompts and open **Rubati**.

For an existing installation, Android should offer an update when signing and
package identity match. If Android reports a conflict or asks you to remove
the existing app, stop and contact support; uninstalling removes local app data.

## Check the download on Windows

In PowerShell, in the folder containing the downloaded APK:

```powershell
Get-FileHash -LiteralPath .\rubati-v1.0.0-beta.1.apk -Algorithm SHA256
```

