# Rubati Android downloads

Rubati is a Kenyan rental marketplace for tenants, landlords and agents.
This separate repository contains download instructions and release notes only.
It does not contain the application's source code.

**No public APK download is available yet.** Version `v1.0.0-beta.1` is being
prepared as an unpublished draft. Publication requires the owner's separate
approval after the remaining acceptance and privacy requirements are completed.

## Planned beta

- Android app: Rubati, version **1.0.0 (3)**.
- Package: `ke.co.renta.app`.
- Android 7.0 or later.
- APK: `rubati-v1.0.0-beta.1.apk` (66,886,156 bytes).
- SHA-256: `77b0da13b0f4501a04817c2cf1e376392b1ada30b8ec97e233e3ac53b271a77e`.

The beta label identifies this distribution; it does not change the APK's
internal version. The APK is signed and was installed on the owner's Samsung
for partial physical acceptance testing. This is not a claim that every
workflow has passed end-to-end testing.

Downloads will be free. Advertising and verification services retain their
applicable fees; a free download does not make those services free.

See [installation instructions](INSTALL.md), [release notes](RELEASE_NOTES.md)
and the [release list](https://github.com/btalexon001/rubati-downloads/releases).
The APK will be attached to a GitHub Release only, never committed to this
repository's file tree.
